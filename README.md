# 티빙 함께보기 프로토타입

소프트웨어공학 개인과제(중간고사 대체)에서 제안한 **티빙 KBO 야구 중계 'To-Be' 시스템**을 실제로 눌러볼 수 있게 만든 웹 프로토타입입니다.
서버 없이 브라우저만으로 동작하며, GitHub Pages로 바로 배포할 수 있습니다.

> 링크 하나로 친구를 초대해 함께 보는 **함께보기** — 응원석 · 승부예측 · 늦은 입장 경기 요약 · 세컨드 스크린(TV)

## 바로 해보기

1. `index.html`을 엽니다. (GitHub Pages 주소 또는 로컬 서버)
2. 폰 화면에서 **함께보기 → 함께보기 방 만들기 → 방 만들고 링크 받기**
3. 링크 화면에서 **손님 탭으로 열기** → 새 탭은 *비구독 손님*으로 동작합니다.
4. 손님 탭에서 **입장하기 → 응원팀 선택 → 경기 요약 → 바로 보기**
5. 두 탭에서 응원석 채팅과 승부예측을 해 보세요. 같은 브라우저의 탭끼리 실시간으로 동기화됩니다.
6. 방장 탭의 **관리**에서 내보내기·링크 재발급·방 종료, **TV**에서 세컨드 스크린 연결을 해 보세요.
7. `admin.html`(운영자 콘솔)에서 체험권 정책·신고 처리·장애 대응을 조작해 보세요.

화면 오른쪽의 **데모 도구**로 경기 속도(×1/×3/×10), 친구 3명 초대, 접속 폭주·요약 장애·예측 장애·방 생성 실패 시뮬레이션을 켤 수 있습니다.

## 구현한 Use Case

| UC | 내용 | 위치 |
|---|---|---|
| UC-01 | 함께보기 방 생성 (대안 흐름 2a·5a·6a 포함) | `#/create` |
| UC-02 | 초대 링크 공유·재발급·폐기 | `#/share/:id` |
| UC-03 | 방 관리 (내보내기·링크·방 종료) | `#/manage/:id` |
| UC-04 | 세컨드 스크린(TV 코드 연결) | `#/second/:id`, `tv.html` |
| UC-05 | 초대 링크로 방 입장 (체험권 4a·4b, 만석·만료·폐기 안내) | `#/landing/:id` |
| UC-06 | 경기 요약 (경기 초반 6a 생략, 장애 시 스코어보드 대체 6b) | `#/summary/:id` |
| UC-07 | 응원팀 득점 장면 모아보기·다시 보기 | `#/clips/:id` |
| UC-08 | 구독 가입(데모 결제) | `#/subscribe/:id` |
| UC-09 | 응원석 선택·채팅·상대 팀 채팅 숨기기 | `#/room/:id` |
| UC-10 | **승부처 예측 이벤트**(만루·득점권·후반 접전에서만 열림)·방 리더보드 (비현금성 보상) | `#/room/:id` |
| UC-11 | 유해 채팅 신고·차단 | `#/room/:id` |
| UC-12~14 | 체험권·보상 정책, 신고 처리·제재, 접속 현황·장애 대응 | `admin.html` |

## 동작 방식

- **경기**: `js/sim.js`가 시드 기반으로 9이닝 경기를 만들고, 공유 시계로 20초에 한 타석씩 진행합니다. 모든 탭이 같은 경기를 봅니다.
- **데이터**: 방·채팅·예측·신고·정책은 `localStorage`에, 사용자(닉네임·구독 여부)는 탭별 `sessionStorage`에 저장합니다. 탭 간 동기화는 `storage` 이벤트를 씁니다.
- **승부처**: 만루, 득점권(2·3루 주자), 8회 이후 2점 차 이내 접전의 타석에서만 예측 이벤트가 열리고 정답은 +30 응원 포인트입니다. 열리면 배너·알림·중계 화면의 '승부처' 표시가 떠요.
- **봇**: 방에 가상 친구 멤버가 들어오면 환영 인사, 사람 채팅에 대한 답장, 경기 상황별 반응(홈런·득점·삼진·공수 교대·승부처)을 자동으로 채팅하고 승부처에서 예측합니다. 결과는 결정적으로 계산해 탭마다 값이 같습니다.
- **한계**: 백엔드가 없어서 *같은 브라우저 안*에서만 방이 공유됩니다. 실제 서비스에서는 서버(WebSocket 등)와 인증·결제 연동이 필요합니다.

경기(두산 vs 한화)·선수·득점·결제는 모두 가상의 데모입니다. 체험권 이닝 수, 링크 유효 시간, 최대 인원 등의 값은 설계 목표(가정)입니다.

## 파일 구조

```
index.html        폰 UI (사용자 앱)
tv.html           TV 화면(세컨드 스크린)
admin.html        운영자 콘솔
css/style.css     공통 스타일
js/sim.js         경기 시뮬레이션·공유 시계
js/store.js       저장소·방 도메인 로직
js/ui.js          UI 공통 도우미(토스트·모달·중계 화면)
js/screens.js     화면별 구현
js/app.js         라우터·데모 도구
js/tv.js          TV 화면 로직
js/admin.js       운영자 콘솔 로직
```

## 로컬 실행

빌드가 필요 없는 정적 사이트입니다. 폴더에서 아무 정적 서버를 띄우면 됩니다.

```bash
python -m http.server 8765
# http://localhost:8765
```

## GitHub Pages 배포

저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 설정하면
`https://<계정>.github.io/<저장소>/` 에서 열립니다.
